◆ connection_factory

using kcenon::database::core::pool::connection_factory = std::function<std::unique_ptr<database_backend>()>

Factory callable that produces a new, initialized database_backend.

Called by the pool when it needs to create a new connection (lazily up to max_size, or to replace a failed one). The backend must be returned in the initialized state. If creation fails, return an empty unique_ptr; the pool will surface the error to the caller of acquire().

Validator callable: returns true if the backend is still usable.

The default validator checks is_initialized(). Backend-specific validators may issue a lightweight "SELECT 1"-style query instead.
